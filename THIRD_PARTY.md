# Third-party attribution and data sources

- TensorFlow.js 4.22.0: https://github.com/tensorflow/tfjs, Apache-2.0. Distribution included as dist/vendor/tf.min.js, obtained from the version-pinned official npm distribution via jsDelivr.
- COCO-SSD 2.2.3: https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd, Apache-2.0. Distribution dist/vendor/coco-ssd.min.js. Model ssdlite_mobilenet_v2 from https://storage.googleapis.com/tfjs-models/savedmodel/ssdlite_mobilenet_v2/model.json and its five weight shards. Weights are pretrained, not trained by OQIM. COCO is used only through pretrained weights; COCO images are not redistributed.
- PariVision: https://github.com/baytoooo/parivision-traffic, AGPL-3.0. Author team: Amal Karimov, Komronbek Qodirov, Aziza Adizova. `site/src/pipeline/tracker.ts` and `geometry.ts` are preserved in vendor-source and transpiled with the IoU correction documented below to dist/vendor/tracker.js and geometry.js (relative import updated). Browser ByteTrack port is based on Ultralytics 8.4.159. The upstream ByteTrack algorithm originates from https://github.com/ifzhang/ByteTrack (MIT); the reused PariVision/Ultralytics-derived implementation is AGPL-3.0. Our line crossing adapter is dist/tracker.js. No junction-specific PariVision rules, proprietary footage, labels or metrics were copied into OQIM.
- Manrope font, Google Fonts / https://github.com/sharanda/manrope, SIL Open Font License 1.1. Optional web font; system sans-serif fallback works without network.
- Synthetic scenarios: generated by OQIM's own engine.js, seeded PRNG and Poisson arrivals, optional scripted demand surge / blockage / parking outflow. No real-world performance claim follows from these scenarios.

Full source is distributed under AGPL-3.0. The inherited tracker sources are pre-existing elimination-stage code and must be attributed when submitting to the final. The public reference site is https://parivision-traffic-test.vercel.app/ .

- PariVision source reference tree: 841ac479b7c10d52991ba6c4819e45455d0a9de5. Detector adapter `detector.ts` is also reused under AGPL-3.0, with input-tensor disposal added in OQIM. YOLO26s ONNX weights (input 544×960) from its public pipeline, originally Ultralytics / COCO, AGPL-3.0.
- ONNX Runtime Web 1.30.0: https://github.com/microsoft/onnxruntime, MIT. Browser WASM runtime included under dist/vendor. WebGPU with single-thread WASM fallback.
- Night sample: Avtocesta, idioterna, 2009-12-14, https://commons.wikimedia.org/wiki/File:Avtocesta.webm, CC BY 3.0, https://creativecommons.org/licenses/by/3.0/. OQIM uses first 12 seconds, scales to 960 pixels, removes audio, encodes H.264. Media keeps CC BY 3.0 independently from software licence.
- Day sample: Street traffic, Editor, 2011-05-28, https://commons.wikimedia.org/wiki/File:Street_traffic.webm, CC BY 3.0, https://creativecommons.org/licenses/by/3.0/. First 12 seconds, scaled to 480 pixels, no audio, H.264. Media retains CC BY 3.0. Plates and faces are not readable in the inspected reduced frames.
- OQIM correction to PariVision tracker: vertical IoU intersection uses max(topA, topB); regression test included.
